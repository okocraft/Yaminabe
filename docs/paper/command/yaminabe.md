# `/yaminabe`

Plugin management commands.

## Usage

| Command                  | Description                                      |
|--------------------------|--------------------------------------------------|
| `/yaminabe dumpcommands` | Prints all registered root command labels.       |
| `/yaminabe reload`       | Reloads the config file and the language files.  |
| `/yaminabe version`      | Prints the version of this plugin.               |

## Permissions

| Permission                      | Description                               |
|---------------------------------|-------------------------------------------|
| `yaminabe.command`              | Required to access `/yaminabe`.           |
| `yaminabe.command.dumpcommands` | Required to run `/yaminabe dumpcommands`. |
| `yaminabe.command.reload`       | Required to run `/yaminabe reload`.       |
| `yaminabe.command.version`      | Required to run `/yaminabe version`.      |
