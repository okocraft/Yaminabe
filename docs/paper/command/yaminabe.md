# `/yaminabe`

Plugin management commands.

## Usage

| Command             | Description                        |
|---------------------|------------------------------------|
| `/yaminabe version` | Prints the version of this plugin. |

## Permissions

| Permission                 | Description                          |
|----------------------------|--------------------------------------|
| `yaminabe.command`         | Required to access `/yaminabe`.      |
| `yaminabe.command.version` | Required to run `/yaminabe version`. |
