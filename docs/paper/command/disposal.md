# `/disposal`

Opens a 4-row menu for discarding items. Items left in the menu are lost when it is closed.

Aliases: `trash`

## Usage

| Command     | Description              |
|-------------|--------------------------|
| `/disposal` | Opens the disposal menu. |

This command can only be run by an in-game player.

## Permissions

| Permission                  | Description                  |
|-----------------------------|------------------------------|
| `yaminabe.command.disposal` | Required to run `/disposal`. |
