# Commands

Commands provided by Yaminabe on Paper/Folia.

| Command                                    | Aliases         | Description                                       |
|--------------------------------------------|-----------------|---------------------------------------------------|
| [`/yaminabe`](yaminabe.md)                 | -               | Plugin management commands.                       |
| [`/anvil`](anvil.md)                       | -               | Opens an anvil menu without the block.            |
| [`/cartographytable`](cartographytable.md) | -               | Opens a cartography table menu without the block. |
| [`/disposal`](disposal.md)                 | `trash`         | Opens a menu for discarding items.                |
| [`/grindstone`](grindstone.md)             | -               | Opens a grindstone menu without the block.        |
| [`/hat`](hat.md)                           | `head`          | Wears the item in the main hand as a hat.         |
| [`/item`](item.md)                         | `i`             | Gives an item to yourself.                        |
| [`/itemlore`](itemlore.md)                 | `lore`, `ilore` | Edits the lore of the item in the main hand.      |
| [`/itemname`](itemname.md)                 | `iname`         | Renames the item in the main hand.                |
| [`/loom`](loom.md)                         | -               | Opens a loom menu without the block.              |
| [`/skull`](skull.md)                       | -               | Gives a player head.                              |
| [`/smithingtable`](smithingtable.md)       | -               | Opens a smithing table menu without the block.    |
| [`/stonecutter`](stonecutter.md)           | -               | Opens a stonecutter menu without the block.       |
| [`/workbench`](workbench.md)               | `craft`         | Opens a crafting table menu without the block.    |

Commands that take text written in MiniMessage share the permissions described in
[Format permissions](../../format-permissions.md).
