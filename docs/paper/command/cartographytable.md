# `/cartographytable`

Opens a cartography table menu without a cartography table block. This is a port of the EssentialsX
`/cartographytable` command.

Aliases: -

## Usage

| Command             | Description                       |
|---------------------|-----------------------------------|
| `/cartographytable` | Opens the cartography table menu. |

This command can only be run by an in-game player.

The menu is not bound to a location, so it stays open wherever the player goes and needs no cartography table block.
Items left in it are returned to the player when the menu is closed.

## Permissions

| Permission                          | Description                          |
|-------------------------------------|--------------------------------------|
| `yaminabe.command.cartographytable` | Required to run `/cartographytable`. |

## Differences from EssentialsX

- EssentialsX registers `carttable` as an alias. Yaminabe does not.
