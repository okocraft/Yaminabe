# `/stonecutter`

Opens a stonecutter menu without a stonecutter block. This is a port of the EssentialsX `/stonecutter` command.

Aliases: -

## Usage

| Command        | Description                 |
|----------------|-----------------------------|
| `/stonecutter` | Opens the stonecutter menu. |

This command can only be run by an in-game player.

The menu is not bound to a location, so it stays open wherever the player goes and needs no stonecutter block. Items
left in it are returned to the player when the menu is closed.

## Permissions

| Permission                     | Description                     |
|--------------------------------|---------------------------------|
| `yaminabe.command.stonecutter` | Required to run `/stonecutter`. |
