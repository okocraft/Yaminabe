# `/grindstone`

Opens a grindstone menu without a grindstone block. This is a port of the EssentialsX `/grindstone` command.

Aliases: -

## Usage

| Command       | Description                |
|---------------|----------------------------|
| `/grindstone` | Opens the grindstone menu. |

This command can only be run by an in-game player.

The menu is not bound to a location, so it stays open wherever the player goes and needs no grindstone block. Items left
in it are returned to the player when the menu is closed.

## Permissions

| Permission                    | Description                    |
|-------------------------------|--------------------------------|
| `yaminabe.command.grindstone` | Required to run `/grindstone`. |
