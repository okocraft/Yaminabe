# `/smithingtable`

Opens a smithing table menu without a smithing table block. This is a port of the EssentialsX `/smithingtable`
command.

Aliases: -

## Usage

| Command          | Description                    |
|------------------|--------------------------------|
| `/smithingtable` | Opens the smithing table menu. |

This command can only be run by an in-game player.

The menu is not bound to a location, so it stays open wherever the player goes and needs no smithing table block. Items
left in it are returned to the player when the menu is closed.

## Permissions

| Permission                       | Description                       |
|----------------------------------|-----------------------------------|
| `yaminabe.command.smithingtable` | Required to run `/smithingtable`. |

## Differences from EssentialsX

- EssentialsX registers `smithtable` as an alias. Yaminabe does not.
