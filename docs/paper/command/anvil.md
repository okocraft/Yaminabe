# `/anvil`

Opens an anvil menu without an anvil block. This is a port of the EssentialsX `/anvil` command.

Aliases: -

## Usage

| Command  | Description           |
|----------|-----------------------|
| `/anvil` | Opens the anvil menu. |

This command can only be run by an in-game player.

The menu is not bound to a location, so it stays open wherever the player goes and needs no anvil block. Items left in
it are returned to the player when the menu is closed.

The experience cost is charged as usual, but the anvil never takes damage, as there is no anvil block to damage.

## Permissions

| Permission               | Description               |
|--------------------------|---------------------------|
| `yaminabe.command.anvil` | Required to run `/anvil`. |
