# `/loom`

Opens a loom menu without a loom block. This is a port of the EssentialsX `/loom` command.

Aliases: -

## Usage

| Command | Description          |
|---------|----------------------|
| `/loom` | Opens the loom menu. |

This command can only be run by an in-game player.

The menu is not bound to a location, so it stays open wherever the player goes and needs no loom block. Items left in
it are returned to the player when the menu is closed.

## Permissions

| Permission              | Description              |
|-------------------------|--------------------------|
| `yaminabe.command.loom` | Required to run `/loom`. |
